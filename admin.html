文章资讯 0 篇

录入标题、正文、封面图。每篇文章一个独立地址 /article/…，前台默认加载俄语（html lang="ru"，方便 Yandex 抓取），可在地址后加 ?lang=zh 或 ?lang=en 切换中/英文；中英内容留空也能正常显示俄语。已发布文章写入 sitemap.xml；草稿仅后台可见。封面请用实景风景照片，不要用预订页面截图。

商业活动 0 条

页面卡片 0 张

全岛游价格方案

游客端打卡点页面分【免拼】【拼团】两个板块独立展示价格。免拼 = 游客包下整台车（座位数含司机），按车型分别填整车包车价，前端会按出行人数自动置灰坐不下的车型；拼团 = 与其他游客拼车按人头付费，按车型分别填单人单价，游客选好车型后前端按所选车型的单价 × 人数自动算总价。
